# Deepfake-ML

**Deepfake-ML** is a machine learning project for detecting fake faces in images. This project focuses on analyzing image data and predicting whether a given face is real or deepfake. It is currently in the development phase.

---

## 🔹 Features
- Detects fake and real faces in images
- Preprocessing and face cropping for better accuracy
- Supports batch predictions on test datasets
- Generates structured JSON outputs for predictions
- Data augmentation applied for robust training

---

## 🔹 Skills & Technologies
- Python
- Pandas & NumPy
- TensorFlow / Keras
- ImageDataGenerator & MTCNN for image preprocessing
- JSON handling & file I/O
